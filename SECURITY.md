# Security Policy

## Supported Versions

Security fixes should be prioritized for actively supported release lines.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub/Gitee
issues.

Use the project's designated private security reporting channel.

When reporting, include:

- Affected version
- Vulnerability description
- Reproduction steps
- Impact assessment
- Suggested mitigation, if known

## Response Target

Target first response:

> Within 24 hours.

The response target is an operational goal and does not constitute a guarantee.

## Disclosure

The project will coordinate remediation and disclosure with the reporter
where appropriate.

Please avoid publicly disclosing exploitable details before a fix or
mitigation is available.
