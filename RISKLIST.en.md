# System Security & Defect Risk List (English)

> This list was generated by AI through automated analysis and testing of the project's source code, configuration files, API implementations, and related project documentation. It records potential security risks, functional defects, code quality issues, and other risks identified during testing.
>
> The risk findings, severity levels, and remediation recommendations in this list all originate from AI testing and analysis results. Some issues may be false positives, false negatives, or require further confirmation against the actual runtime environment. Therefore, this list primarily serves as a reference for project risk identification, troubleshooting, and follow-up remediation, and is **not equivalent to a manual security audit, penetration test, or third-party security certification.**
>
> As the project evolves through development, testing, and version iterations, this list will be continuously updated through AI-assisted testing and manual review.

## List Description

* **Testing Method**: AI automated code analysis, static checks, logic analysis, and related testing
* **Analysis Scope**: Project source code, configuration files, APIs, and related project documentation
* **Risk Scope**: Security risks, functional defects, code quality, configuration risks, data risks, and other potential issues
* **Risk Levels**: 🔴 Critical / 🟠 High / 🟡 Medium / ⚪ Low
* **Conclusion Nature**: AI testing and analysis conclusions; requires manual review against the actual environment
* **Maintenance**: Continuously updated as the project version iterates

> **Special Note:** This list is intended to assist with project development and quality management. It does not constitute a guarantee that the system is free of security vulnerabilities or other defects.

## 3. AI Service (FastAPI `/ai`) Control-Plane Exposure

> Common root cause: `AI_consultant/api.py` has **no authentication at all**; CORS wildcard + credentials; `uvicorn` binds `0.0.0.0:8000`; FastAPI `/docs` enabled by default. Anyone who can reach port 8000 is an "admin". The backend `SecurityConfig` also permits `/ai/**`, and the frontend admin pages connect directly to this service **without a token**, so "only accessible from the admin menu" is the sole line of defense.

| ID | Level | Risk Item | Current Status & Impact | Location | Remediation |
| --- | --- | --- | --- | --- | --- |
| C1 | 🔴 Critical | `/ai` all routes unauthenticated, CORS `*` + credentials, listening on 0.0.0.0 | Control plane fully open | `AI_consultant/api.py:30-39` (and all routes)、`AI_consultant/main.py:1733-1735` | Add API-Key/server-side token validation to `/ai` (issued by backend, frontend proxied through backend); close public exposure |
| C4 | 🔴 Critical | Unauthorized rewriting of model `base_url` etc. config | Sends real provider API Key to attacker's server | `AI_consultant/api.py:297-316`、`main.py:1719-1724` | Write operations like `base_url`/system prompt only allowed from backend |
| C5 | 🔴 Critical | `DELETE /ai/memory`, knowledge-base CRUD, `/seo/generate`, `reembed` without auth | Can globally delete data / burn LLM cost | `AI_consultant/api.py:613-616,736-954` | Authenticate all + isolate by identity |
| C6 | 🟠 High | Cross-user shared Redis `active_session` key | On worker restart/failover may resume another user's session; multi-worker doubles in-memory rate-limit counters | `AI_consultant/db.py:95-111`、`main.py:943-950`、`rate_limit.py:101-169` | Bind session key to real authenticated identity |
| C7 | 🟠 High | Rate limiting bypassable | guest counted by client `visitor_id`/`session_id`, user by request-body `username`; rotation bypasses "5/day, 30/min"; Redis-failure degrades to per-worker memory count with unbounded dict growth | `api.py:96-103`、`rate_limit.py` | Bind to server-issued identity; limit dict growth |
| C8 | 🟡 Medium | `/docs`、`/openapi.json` exposed by default; `migrate.py` `drop_tables()` has no protection switch | API docs / destructive script reachable | `AI_consultant/api.py:30`、`migrate.py:25-28` | Disable docs in production; add protection switch to drop |
